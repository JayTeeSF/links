6) How to send data to a central database (i.e. restdb.io):
# See the restdb.io docs for how-to format these urls: https://restdb.io/docs/rest-api#restdb

# A) Set some variables:
export API_KEY="..." # <-- get this from your account on the restdb.io website...

# typically your program will set these values:
export device="Dev1"
export current_temperature="72"
export timestamp=`date +%s`

# finally, send data to your program -- notice that each attribute starts with an upper-case letter
curl -k -H "Content-Type: application/json" -H "x-apikey: ${API_KEY}" -X POST 'https://firewire-dc22.restdb.io/rest/temperatures' -d "{\"Device\": \"${device}\", \"Temperature\": ${current_temperature}, \"Timestamp\": ${timestamp}, \"Alert\": false}"


# B) How to read (all the) data from the database:
curl -H "Content-Type: application/json" -H "x-apikey: ${API_KEY}" -X GET 'https://firewire-dc22.restdb.io/rest/temperatures'

# sample output:
# [
#  {"_id":"5e19341a688c77570003788c","Device":"Dev1","Temperature":72,"Timestamp":1578707288}
# ]

# How to mark an existing record in your database as an alert (using the "_id" value above):
curl -H "Content-Type: application/json" -H "x-apikey: ${API_KEY}" -X PUT 'https://firewire-dc22.restdb.io/rest/temperatures/5e19341a688c77570003788c' -d "{\"Device\": \"${device}\", \"Temperature\": ${current_temperature}, \"Timestamp\": ${timestamp}, \"Alert\": true}"
